# Architecture diagrams

- `zero-trust-architecture.png`: readable raster preview of six proposed identity paths.
- `zero-trust-architecture.svg`: accessible vector diagram, suitable for scaling and export.

Repeated Entra and S3 nodes in the visual represent the same services viewed along different paths. Blue lanes describe Azure; orange lanes describe AWS. Monitoring and recovery span both clouds. None of these controls was deployed in Project 6.
